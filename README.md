# 7-Eleven_Gift_Card
7-Eleven 商品卡單機管理工具：儲存兩段條碼、出示付款條碼、手動記錄餘額，支援 JSON 匯出與合併匯入；重複卡片採用最新餘額並保留歷史紀錄，資料僅存於本機瀏覽器。

本工具為非官方的個人商品卡管理工具，支援 Safari 開啟及加入 iPhone 主畫面。

主要功能：
- 掃描或手動輸入兩段條碼，不必保存卡片照片。
- 顯示付款條碼、各卡記錄餘額與合計。
- 手動更新餘額，保留修改時間與歷史紀錄。
- 用完歸檔；垃圾桶保留 30 天，逾期於開啟時清除。
- 透過 JSON 檔案分享、備份及接收卡片。
- 以兩段條碼辨識重複卡，採用最後更新的餘額並記錄合併結果。
- 自訂暱稱、卡夾名稱及頭像。

卡片資料僅存於目前瀏覽器，不會自動上傳或跨裝置同步。餘額為手動紀錄，並非官方即時餘額。JSON 包含完整付款條碼且未加密，請妥善保管，勿上傳至公開儲存庫。
